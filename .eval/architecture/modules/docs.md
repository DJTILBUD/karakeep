# Module: docs

Configures and builds the documentation website for Karakeep using Docusaurus, integrating OpenAPI documentation generation and Algolia search.

## Key files
- `docs/docusaurus.config.ts`: Main Docusaurus configuration specifying site metadata, plugins, theme options, Algolia search credentials, and OpenAPI plugin settings referencing the Karakeep OpenAPI specification.
- `docs/sidebars.ts`: Configures the documentation sidebar structure, combining autogenerated document links with the generated OpenAPI sidebar.
- `docs/babel.config.js`: Babel configuration resolving the Docusaurus core Babel preset.

## Public interface
- default export (Config) from docs/docusaurus.config.ts
- default export (SidebarsConfig) from docs/sidebars.ts
- module.exports from docs/babel.config.js
