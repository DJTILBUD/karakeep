# Module: docs/versioned_docs

Maintains versioned API sidebar navigation configurations across historical documentation releases (v0.28.0 through v0.34.0) for Docusaurus.

## Key files
- `docs/versioned_docs/version-v0.28.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.28.0
- `docs/versioned_docs/version-v0.29.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.29.0
- `docs/versioned_docs/version-v0.30.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.30.0
- `docs/versioned_docs/version-v0.31.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.31.0
- `docs/versioned_docs/version-v0.32.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.32.0
- `docs/versioned_docs/version-v0.33.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.33.0
- `docs/versioned_docs/version-v0.34.0/api/sidebar.ts`: API documentation sidebar configuration for version 0.34.0

## Public interface
- sidebar: SidebarsConfig (exported API sidebar configuration object per version)
